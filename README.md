# 两汉故事：从秦末到汉朝建立

一本用《明朝那些事儿》那种写法重讲秦末汉初的书。14 章，约 6.1 万字，329 条脚注。

底本为《史记》《汉书》。事件、人物、大部分对话有史料依据；现场、动作、心理分析带有小说的笔法和推断；引号里的话能查到出处的照录原文，出处写在脚注里。

## 在线阅读

打开 `index.html` 就是目录，一章一页，正文里的 ①②③ 点一下会弹出脚注。手机可以直接看。

`book.html` 是整本合成一页的版本，方便一次性搜索或打印。
